# Blocks

A personal, local-first goal & training tracker (PWA). See `blocks-app-prompt.md` for the full spec.

## Stack

React 18 + TypeScript + Vite, Tailwind CSS, Dexie.js (IndexedDB), vite-plugin-pwa. No backend, no accounts — everything lives in the browser.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
